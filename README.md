# Smart Cane

A multidisciplinary senior-design assistive-device project combining embedded systems, electronics, sensing, hardware integration, physical prototyping, and a Bluetooth-connected mobile interface.

## Project overview

Smart Cane is a team capstone project centered on the design and prototyping of a smart-cane assistive device. The project brings together embedded software, electronics, sensors, mechanical packaging, and iterative prototype integration.

## Engineering contributions

### Mechanical packaging and physical integration

- Designed the cane-mounted enclosure and attachment geometry, including dimensions, weight considerations, accessibility, and physical usability.
- Designed the internal packaging for the PCB, battery, connectors, and related components, accounting for physical size, weight, location, and assembly fit.
- Integrated the virtual PCB into the final assembly model; the CAD work served as the basis for 3D-printed physical parts.

### PCB physical design and hardware realization

- Converted the preliminary PCB concept into a production-ready physical design by specifying component footprints, board dimensions, and placement constraints.
- Coordinated board geometry with enclosure packaging and connector access.
- Incorporated the fabricated board's virtual representation into the final assembly model.

### Embedded software and mobile interface

- Programmed compass and RFID functions used in the navigation logic.
- Created the mobile app used to connect to Smart Cane, visualize system information, and operate the assistant through Bluetooth.
- Worked across the data path linking RFID and compass information to the user-facing mobile interface.

## Verified project scope
