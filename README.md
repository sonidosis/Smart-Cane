# Smart Cane

A multidisciplinary assistive-device engineering project that combines embedded systems, electronics, sensing, hardware integration, and companion/mobile application work.

## Project overview

Smart Cane is a capstone/portfolio project centered on the design and prototyping of a smart-cane assistive device. The project brings together embedded software, electronics, sensors, mechanical packaging, and iterative prototype integration.

## Verified project scope

- Microcontroller-based implementation
- Proximity sensing
- Compass functionality
- RFID functionality
- Bluetooth connectivity
- Haptic feedback
- Power circuitry
- Custom enclosure and internal hardware layout
- PCB and battery packaging considerations
- 3D-printed prototype integration
- Weight, fit, and manufacturability considerations
- Companion/mobile application work
